女武神项目（Project Valkyrie）评估代码生成与仓库修复智能体在面对恶意注释注入与依赖投毒时的防御能力。

## 课题代号与成员

女武神项目内部代号为 VK-608，由林可担任项目组长，裴敬负责红队攻击脚本编写，评测沙箱运行在独立隔离网段 10.88.0.0/24。

## 攻击场景设计

基准包含 240 个真实 Python 与 Rust 仓库修复任务，涵盖隐藏在文档字符串中的越权文件读取指令、伪造单元测试通过信号以及恶意构建脚本触发三类对抗攻击。

## 防御基线表现

实验表明，在工具执行层增加只读文件系统挂载与出站网络全阻断策略后，恶意指令攻击成功率从无防护时的 34.2% 下降至 0.8%，正常补丁解决率保持在 52.5%。
