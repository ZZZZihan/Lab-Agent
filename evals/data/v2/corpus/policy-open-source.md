清衡实验室鼓励将论文配套代码与基准数据集向学术界开源，但在公开仓库前必须完成许可证兼容性审查与敏感信息剥离。

## 默认开源协议

实验室自研推理框架与评测脚本默认采用 Apache-2.0 许可证发布；公开合成语料集与标注指南默认采用 CC-BY-4.0 协议。未经导师书面批准，禁止引入 AGPL-3.0 或商业限制性源码依赖。

## 发布前清理清单

开源仓库在切换为 Public 之前，必须新建干净的导出提交，彻底剥离内网域名、历史校准日志与内部机器主机名，并由合规专员林可在发布审批单（编号 OS-CHECK-09）上签字确认。

## 第三方权重声明

若开源项目依赖外部预训练模型权重（如 Qwen3-Embedding 或 BGE 系列），README 必须单列模型来源、原始许可证名称及固定 revision 哈希，禁止将第三方权重直接打包进代码仓库的 Git LFS。
