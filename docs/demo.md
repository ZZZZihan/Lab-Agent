# Lab Agent 10 分钟端到端演示脚本

本文档提供一份约 10 分钟的现场演示脚本，覆盖 **登录、多格式异步上传、带引用流式问答、证据门控拒答、权限隔离、审计查看（含无原文核验）** 六个核心环节，以及 **「关掉嵌入校准会怎样」** 与 **「在 Magpie 用量页查看独立统计」** 两个验证环节。

---

## 0. 演示前准备（约 1 分钟）

### 真实模式启动（推荐，Apple Silicon Mac Studio）

1. 确认已将 Lab Agent 专用的 Magpie 密钥保存在 `~/.config/lab-agent/magpie.key`（权限 `600`）：
   ```bash
   mkdir -p ~/.config/lab-agent && chmod 700 ~/.config/lab-agent
   pbpaste > ~/.config/lab-agent/magpie.key && chmod 600 ~/.config/lab-agent/magpie.key
   ```
2. 确认宿主机 Ollama 正在运行且已拉取 `qwen3-embedding:8b`：
   ```bash
   brew services start ollama
   ollama pull qwen3-embedding:8b
   ```
3. 执行一键启动与自动冒烟脚本：
   ```bash
   export LLM_MODEL=claude-sonnet-5-5
   ./scripts/demo.sh
   ```
   > 若处于无网或无网关环境，可执行 `./scripts/demo.sh --offline` 使用离线模式（`hashing` + `fake`）走完同一套流程。

4. 脚本输出全部 `PASS` 后，浏览器打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

## 1. 多角色登录（约 1 分钟）

- **操作**：
  1. 在登录页 `/login` 查看下方「本地演示账号」表格：
     - **沈昭**（`admin@lab.local`，`admin`）：管理员，拥有全部文档可见性与「审计」页权限；
     - **林可**（`member@lab.local`，`member`）：成员，被显式授权可阅读受限文档「项目赫利俄斯」；
     - **周宁**（`zhou@lab.local`，`member`）：成员，可阅读「采购笔记」，未获「项目赫利俄斯」授权；
     - **王敏**（`viewer@lab.local`，`viewer`）：查看者，只能阅读实验室公开文档，不能上传。
  2. 先后点击或输入账号登录，并点击右上角 `EN` / `中文` 按钮切换界面语言。
- **预期画面**：
  - 顶栏右侧显示当前登录人的姓名与角色（如 `林可 member`）；
  - 只有以管理员 **沈昭** 登录时，顶栏导航才会出现「审计」入口；
  - 顶部**没有**黄色未校准横幅（因为 `demo.sh` 已完成校准检查）。
- **讲解要点**：
  - 浏览器仅持有 `httpOnly` Cookie `la_session`，前端 Next.js 代理路由在服务端将 Cookie 置换为 `Authorization: Bearer` 转发给 FastAPI，并附带 `X-Internal-Proxy-Secret` 签名的 `X-Client-IP`；
  - 种子账号仅用于本地演示，`APP_ENV=prod` 时拒绝写入；双桶登录限流分别按客户端 IP（30 次/60 秒）与账号哈希（10 次/900 秒）独立计数。

## 2. 多格式异步上传与状态流转（约 2 分钟）

- **操作**：
  1. 以成员 **林可**（`member@lab.local`）登录，点击顶部导航进入「文档」页 `/documents`。
  2. 点击右上角「上传文档」，演示三种输入：
     - **Markdown（`.md`）**：切换到「选择文件」，选择一份带 `##` 二级标题的 `.md` 笔记（或使用「粘贴文本」粘贴含 `## 低温杜瓦罐操作规范\n液氮补给阀额定压力上限为 350 kPa，每 14 天巡检一次。` 的笔记），可见性选「实验室可见」，点击「入库」。
     - **PDF（`.pdf`）**：再次点击「上传文档」→「选择文件」，选择一份多页文字版 `.pdf` 手册（标题会自动按文件名填充），点击「入库」。
     - **纯文本（`.txt`）**：选择一份不含 `##` 标题的 `.txt` 实验记录并提交。
- **预期画面**：
  - 每次点击「入库」后接口立即返回 `202 Accepted`，弹窗关闭；
  - 文档列表中新文档右侧先显示灰色的 **「处理中」**（`pending` / `processing`）徽章；
  - 页面每 2 秒自动轮询一次，待后台 worker 调用宿主机 Ollama（`qwen3-embedding:8b`）完成切块与 4096 维嵌入后，徽章自动变为 **「就绪」**（`ready`），标题变为可点击链接（全部就绪后自动停止轮询）。
- **讲解要点**：
  - 8B 嵌入模型同步处理大文件会阻塞请求，因此上传只负责落库并标记 `pending`，由 API 进程内的异步 worker 用 `SELECT ... FOR UPDATE SKIP LOCKED` 领取任务，失败最多重试 3 次，支持扫描版/加密 PDF 明确报错（422 `pdf_no_text` / `pdf_encrypted`）；
  - 切块策略按格式自适应：Markdown 按 `##` 小节切分（超长单段按句末标点与窗口兜底）、PDF 按页切分并标注 `第 p 页`、纯文本按段落与重叠窗口切分并标注 `第 i 段`。

## 3. 带引用流式问答与引用后校验（约 2 分钟）

- **操作**：
  1. 保持在 **林可** 账号下，切换到「问答」页 `/chat`。
  2. 针对刚才上传的文档提问（例如：`“液氮补给阀的额定压力上限是多少？多久巡检一次？”`，或询问刚上传的 PDF 内容），也可以点击建议问题（如 `“周三学术例会在哪间实体会议室？”`）。
  3. 回答生成完毕后，点击句末的 `[1]` 上标，再点击下方引用卡片上的「打开原文」。
- **预期画面**：
  - 提问后先显示中文工具阶段状态：`检索实验室文档`；
  - 随后流式输出经本机 Magpie 网关调用的真实大模型回答，每句话末尾带有 `[1]` 等可点击上标；
  - 点击 `[1]` 平滑滚动并高亮对应的「依据」卡片，卡片标明文档标题、小节名（或 PDF 的 `第 N 页`）以及原文摘录；
  - 点击「打开原文」进入 `/documents/<id>` 查看完整文档。
- **讲解要点**：
  - Agent 首轮固定调用全库检索 `search_knowledge_base`（`k=12`），不按关键词窄化 `collection`，避免用户把项目笔记传进通用知识库时漏检；
  - 送入 LLM 的证据用 `<evidence id="n">` 包裹并转义闭合标签，系统提示词明确声明忽略证据内的任何指令（防提示词注入）；
  - 流式生成结束后执行 `check_citations` 后校验：只保留模型实际引用的有效编号 `[n]` 作为最终落库和展示的引用，剔除越界编号。

## 4. 证据门控拒答（不调用大模型）（约 1.5 分钟）

- **操作**：
  1. 在「问答」页输入一个语料库里完全不存在的问题：`“火星基地的氧气配额是多少？”`（或 `“实验室量子对撞机的冷却液配方是什么？”`）。
- **预期画面**：
  - 系统**不会**流式编造答案，而是直接显示琥珀色拒答卡片：**「检索证据不足，未生成答案」**；
  - 卡片中明确列出本次检索的 **决策分数**（top-1 余弦相似度）、当前嵌入指纹的 **阈值**（`threshold`）以及 **稀有词覆盖**；
  - 下方列出词面最相近的邻居段落（注明日记/笔记只是词面邻居而非答案）。
- **讲解要点**：
  - 拒答判定发生在调用大模型**之前**：当决策分数低于 dev 集校准的 `evidence_score_min` 时直接短路返回，**完全不调用 LLM**（零幻觉、零网关 token 消耗）；
  - 若某道题词面高度重合越过了检索阈值，但证据内容不足以回答，大模型输出约定句 `无法根据现有文档回答` 时，后端还会将其转换为 `model_declined` 二次拒答（「模型判断证据不足，未生成答案」）。

## 5. 检索时权限隔离（ACL 下推 SQL）（约 1.5 分钟）

- **操作**：
  1. 在 **林可**（已获「项目赫利俄斯」授权）账号下提问：`“赫利俄斯项目的内部代号和负责人是什么？”`，记下引用卡片中赫利俄斯文档的 URL `/documents/<helios-id>`。
  2. 点击右上角「退出」，切换为 **周宁**（`zhou@lab.local`，未获「项目赫利俄斯」授权）登录。
  3. 在「问答」页提问同样的问题：`“赫利俄斯项目的内部代号和负责人是什么？”`。
  4. 在浏览器地址栏直接访问刚才记下的 `/documents/<helios-id>`。
  5. 退出并切换为查看者 **王敏**（`viewer@lab.local`，`viewer`）登录，进入「文档」页。
- **预期画面**：
  - **林可** 提问时：准确回答内部代号 `HX-17`、负责人陈予安，并引用受限文档「项目赫利俄斯」；
  - **周宁** 提问时：触发拒答，且下方的最近邻证据中也**绝不出现**任何「项目赫利俄斯」的段落；
  - **周宁** 直接访问 `/documents/<helios-id>` 时：返回 `404 文档不存在`（不泄漏文档是否存在），同时后台记录一条 `permission_denied` 审计事件；
  - **王敏** 进入「文档」页时：右上角没有「上传文档」按钮，仅显示「查看者不能上传。」。
- **讲解要点**：
  - 权限控制（`acl_sql()`）直接作为 SQL 谓词下推在 pgvector 向量检索与全文检索的 `WHERE` 子句里，未授权的块在数据库层就被排除，绝不是“先取全局 top-k 再在应用层过滤”。

## 6. 审计页可读性、游标分页与「审计无原文」核验（约 1 分钟）

- **操作**：
  1. 退出并切换为管理员 **沈昭**（`admin@lab.local`）登录，点击顶部导航「审计」进入 `/audit`。
  2. 查看审计表格的五列：**时间**、**操作者**（显示真实姓名如 `林可`、`周宁`、`王敏`、`沈昭`，不暴露邮箱）、**动作**（中英文名称 + 动作编码）、**资源**（资源类型与 ID）、**细节**（键值对小表格）。
  3. 使用右上角「动作」下拉框依次筛选：
     - `login`（登录）
     - `document_upload`（上传文档）与 `document_indexed`（文档入库完成）
     - `retrieval`（检索）
     - `llm_call`（模型调用）
     - `answer_refused`（拒绝作答）
     - `permission_denied`（越权拒绝）
  4. 切回「全部动作」，滚动到表格底部，点击 **「加载更早」** 按钮测试游标分页。
  5. **核验审计不含原文**：在页面使用浏览器查找（`Cmd+F`）搜索刚才提问的 `“火星基地”`、`“氧气配额”`、`“液氮补给阀”` 或任何用户邮箱。
- **预期画面**：
  - 下拉框可按 15 类标准审计动作即时过滤；点击「加载更早」按 `before_id` 游标无缝追加更早的记录且不重不漏；
  - `llm_call` 的细节小表格中记录了 `model`、`prompt_tokens`、`completion_tokens`、`citations_used`、`redaction_count`、`status`，但浏览器搜索问题原文、答案正文、文档正文或邮箱均为 **0 命中**。
- **讲解要点**：
  - `audit_events` 表由 PostgreSQL 触发器强制只追加（拒绝 `UPDATE`，普通事务拒绝 `DELETE`）；
  - 写入前经过 `sanitize_detail` 严格拦截 `question`、`prompt`、`content`、`answer`、`email` 等敏感键名，客户端 IP 使用 HMAC 截断哈希存储。

## 7. 验证环节 A：关掉嵌入校准会怎样（失败关闭与未校准横幅）（约 0.5 分钟）

- **操作**：
  1. 在终端临时移走当前指纹的校准文件并重启 `api`（使系统处于未校准状态）：
     ```bash
     docker compose exec api sh -c 'mkdir -p /tmp/cal-bak && mv /app/data/calibrations/*.json /tmp/cal-bak/ 2>/dev/null || true'
     docker compose restart api
     ```
  2. 刷新浏览器任意页面，并查看 `curl -fsS http://127.0.0.1:43124/api/v1/health | jq '{calibrated, calibration_source}'`。
  3. 在问答页尝试提问任意问题，随后恢复校准文件并重启：
     ```bash
     docker compose exec api sh -c 'mv /tmp/cal-bak/*.json /app/data/calibrations/ 2>/dev/null || python -m evals.run_eval --tune'
     docker compose restart api
     ```
- **预期画面**：
  - 未校准时：`/api/v1/health` 返回 `"calibrated": false, "calibration_source": null`；
  - 前端顶栏下方立即出现醒目的黄色警告横幅：**「当前嵌入模型尚未校准，系统会拒答绝大多数问题。请运行校准（见 README）。」**；
  - 此时提问任何问题，拒答阈值都会回退到失败关闭值 `0.99` 而安全拒答；恢复校准文件并重启后，黄色横幅消失，问答恢复正常。
- **讲解要点**：
  - 不同嵌入模型、不同维度或不同 instruction 模板的余弦分布完全不同。Lab Agent 将校准文件与 `embedding_fingerprint` 强绑定，杜绝“换了嵌入模型却沿用旧阈值导致全部误答或静默失效”。

## 8. 验证环节 B：在 Magpie 用量页查看 Lab Agent 的独立统计（约 0.5 分钟）

- **操作**：
  1. 打开本机 Magpie 网关的管理界面（Usage / API Keys 页面），定位到为 Lab Agent 单独签发的网关密钥（对应 `~/.config/lab-agent/magpie.key`）。
- **预期画面**：
  - 该密钥名下清晰记录了刚才「环节 3」和「环节 5（林可提问）」产生的调用次数、模型名（如 `claude-sonnet-5-5`）以及 prompt / completion token 统计，与审计页 `llm_call` 事件中的 token 用量完全吻合；
  - 「环节 2」的文档入库嵌入、「环节 4」的拒答提问、以及「环节 7」的阈值校准均**没有**产生任何 Magpie 调用。
- **讲解要点**：
  - 每个客户端使用独立的 Magpie 密钥，既实现精确的成本归因，又能在密钥轮换或吊销时互不影响；
  - 嵌入与阈值校准全部在 Mac Studio 本机 Ollama（`qwen3-embedding:8b`）上完成，不消耗外部大模型配额。
